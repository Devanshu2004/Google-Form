# Data Liberation Project – Get Involved form

A custom-designed volunteer/interest form for the Data Liberation Project (a MuckRock Foundation project). Responses are submitted to the project's existing Google Form, so they land in the Form's Responses tab and its linked Sheet.

Plain static files (`index.html`, `style.css`, `script.js`): no framework and no build step. Hosted on GitHub Pages.

## Updating questions

If the Google Form changes, edit the `CONFIG` object at the top of `script.js`. Entry IDs and option text must match the Google Form exactly, including curly apostrophes (’).
